# SKILL.md 建立教學

互動式教學，引導使用者從零到一建立第一個 SKILL.md 技能。

## 步驟

1. **詢問**使用者想要技能做什麼（程式碼審查、部署、生圖等）
2. **引導**命名與選擇存放位置（全域 vs 專案）
3. **逐步建立** Frontmatter（name / description / license / compatibility）
4. **說明**技能目錄結構（scripts / references / assets 的用途與取捨）
5. **產生** SKILL.md 主體內容
6. **設定** opencode.json 權限
7. **驗證**用 agnix 檢查格式
8. **詢問**是否要發布分享

詳細內容見根目錄的 [24-SKILL.md-建立教學.md](../../24-SKILL.md-建立教學.md)。
