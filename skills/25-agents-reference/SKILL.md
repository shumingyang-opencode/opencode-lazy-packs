# AGENTS.md 建立教學

互動式教學，引導使用者依專案特性建立 AGENTS.md。

## 步驟

1. **詢問**專案基本資料（名稱、語言、框架、用途）
2. **說明**AGENTS.md 的三個層級（全域 / 專案 / 本機覆蓋）
3. **列出**可選章節讓使用者勾選（目錄結構 / 編碼慣例 / 測試 / Git 流程 / 部署）
4. **逐章撰寫** — 對每個勾選的章節，說明用途後產生對應內容
5. **詢問**是否要一併建立全域 AGENTS.md
6. **驗證**重啟 OpenCode 確認載入成功
7. **說明**團隊共享方式（提交 Git）

詳細內容見根目錄的 [25-AGENTS.md-建立教學.md](../../25-AGENTS.md-建立教學.md)。
