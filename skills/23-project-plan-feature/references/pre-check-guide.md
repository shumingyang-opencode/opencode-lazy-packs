# Pre/Post Check Guide — Analysis Docs Audit

## Pre-Check (Before Planning)
1. Review existing analysis docs against the current codebase
2. Cross-reference against analysis docs
3. If inconsistencies found: STOP and fix docs first

## Post-Check (After Implementation)
1. Re-check analysis docs against the final codebase
2. Check for new classes/modules not in analysis docs
3. Request updates to analysis docs as needed
